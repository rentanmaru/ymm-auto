Privacy Policy / プライバシーポリシー

最終更新日: 2026-05-08

YMM Auto Uploader (以下「本ツール」) は、開発者本人のSNSアカウントへの自動投稿のみを目的としたパーソナル開発ツールです。本ポリシーは本ツールが取り扱う情報について定めます。

1. 取得する情報

本ツールは以下の情報のみをローカル環境で取り扱います:

  • YouTube Data API のOAuthトークン: 動画アップロード認証用
  • TikTok Content Posting API のOAuthトークン: 動画投稿認証用
  • 動画ファイル (.mp4): 投稿対象のコンテンツ
  • 動画メタデータ: タイトル、説明文、タグ、サムネイル

これら情報はすべて開発者本人のローカルWindows PC内で生成・処理されます。

2. 情報の利用目的

取得した情報は以下の目的にのみ使用します:

  • YouTubeおよびTikTokへの動画投稿認証 (OAuthトークン)
  • 動画ファイルおよびメタデータの投稿 (各APIへの送信)

マーケティング・分析・第三者提供等の目的では一切使用しません。

3. 情報の保管

  • OAuthトークン: ローカルファイルシステムに暗号化されたJSON形式で保存。.gitignore により外部公開リポジトリには含まれません
  • 動画ファイル: 投稿後はローカルにのみ残ります。クラウドへのバックアップは行いません
  • 保管期間: ユーザー(開発者本人)が手動削除するまで保持

4. 第三者提供

本ツールは取得した情報を第三者に提供することはありません。ただし、以下の公式APIに対してのみ、投稿に必要な範囲で情報を送信します:

  • Google YouTube Data API v3
  • TikTok Content Posting API

5. クッキー・トラッキング

本ツールはクッキーを使用しません。アクセス解析・行動追跡も行いません。

6. 情報の削除請求

本ツールはローカル環境のみで動作するため、開発者本人がファイル削除を行うことで完全削除が可能です。サーバー側に保管する情報はありません。

7. ポリシーの変更

本ポリシーは予告なく変更される場合があります。変更時はこのページに最終更新日と共に反映します。
