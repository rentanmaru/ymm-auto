YMM Auto Uploader

YouTube Shorts / TikTok 縦型動画の自動投稿ツール

YMM4 (ゆっくりムービーメーカー4) で生成した縦型 Shorts 動画 (1080×1920 / 60fps) を、自身のSNSアカウントへ自動投稿するためのパーソナル開発ツールです。

機能概要

  • JSON形式のテーマ定義からYMM4プロジェクト(.ymmp)を自動生成
  • VOICEVOX (ずんだもん) による音声合成の自動埋め込み
  • Wikimedia Commons 等の商用OK素材の自動収集
  • YouTube Data API v3 による自動アップロード (実装済)
  • TikTok Content Posting API による自動投稿 (本ツールで申請中)

利用主体

本ツールは開発者本人 (@rentanmaru、TikTokおよびYouTubeアカウント所有者) のコンテンツ投稿のみを目的としています。第三者アカウントへの代理投稿機能は含まれません。

技術スタック

  • Python 3.12 / PowerShell 5.1 (Windows)
  • VOICEVOX 0.25.x (ローカル音声合成エンジン)
  • YouTube Data API v3
  • TikTok Content Posting API (申請中)
  • Wikimedia Commons / NASA 公式素材
